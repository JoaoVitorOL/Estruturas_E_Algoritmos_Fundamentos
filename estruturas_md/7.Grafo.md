# 🕸️ Grafos (PT-BR)

## 🎯 Função principal

Um **Grafo** é uma estrutura de dados **não linear**, **dinâmica** e **altamente genérica**, utilizada para modelar **relações arbitrárias** entre entidades.

Diferente de listas e árvores:

- Não existe hierarquia obrigatória  
- Não existe noção de “primeiro” ou “último”  
- Um elemento pode se relacionar com **vários outros simultaneamente**

Formalmente, um grafo é definido como:

```text
G = (V, E)

V → conjunto de vértices (nós)
E → conjunto de arestas (ligações)
````

## 🧠 Origem teórica
A Teoria dos Grafos surge em 1736 com **Leonhard Euler**, ao resolver o problema das **Sete Pontes de Königsberg**:
> Seria possível atravessar todas as pontes uma única vez, sem repetir nenhuma?
Esse problema mostrou que:
> A **estrutura** das conexões importa mais do que as distâncias físicas
> Relações podem ser estudadas matematicamente

## 🌍 Aplicações práticas
Grafos aparecem naturalmente em problemas reais:

- Rotas e mapas
- Redes de computadores
- Redes sociais
- Malhas ferroviárias
- Circuitos eletrônicos
- Dependências entre tarefas
- Sistemas de recomendação

## 🧱 Elementos fundamentais

### 🔹 Vértice (ou Nó)
Representa uma entidade do problema:
- Cidade
- Pessoa
- Computador
- Estado
- Página

### 🔹 Aresta
Representa a **relação entre dois vértices**:
- Estrada
- Conexão
- Amizade
- Comunicação

---

## 🧭 Tipos de grafos

### 🔹 Grafo não orientado
```text
A ─── B
````
- A ligação não tem direção
- A → B é o mesmo que B → A

### 🔹 Grafo orientado (dígrafo)
```text
A ──▶ B
````
- A direção importa
- A → B ≠ B → A

### 🔹 Grafo ponderado
```text
A ──(5)──▶ B
````
- Cada aresta possui um peso
Peso pode representar:
- distância
- custo
- tempo
- latência

  ---

  ## 🧠 Terminologia essencial
  
**Adjacente**: vértices ligados por uma aresta
**Grau**: número de arestas incidentes em um vértice
**Caminho**: sequência de vértices conectados
**Ciclo**: caminho que começa e termina no mesmo vértice
**Conectado**: existe caminho entre quaisquer dois vértices

## 🧠 Representações de grafos (MEMÓRIA)

### 1️⃣ Matriz de Adjacência
Estrutura:

- Matriz V x V
- Valor indica se existe ligação

```text
    A B C
A [ 0 1 0 ]
B [ 1 0 1 ]
C [ 0 1 0 ]
````
Características:

- Acesso O(1)
- Consome muita memória
- Boa para grafos densos

### 2️⃣ Lista de Adjacência (mais usada)
Cada vértice mantém uma lista de vizinhos:

```text
A → B
B → A → C
C → B

````
Características:

- Menor consumo de memória
- Melhor para grafos esparsos
- Percurso eficiente


---

### 🔍 Busca em Profundidade (DFS)
Conceito:
- Explora o máximo possível antes de retroceder
- Usa Pilha (explícita ou recursão)

Regras lógicas: <br>
1. Visita um vizinho não visitado <br>
2. Marca e empilha <br>
3. Se não houver vizinho, desempilha <br>
4. Repete até esgotar <br>

```text
A → B → D → H → I

````

### 🔍 Busca em Largura (BFS)
Conceito:
- Explora nível por nível
- Usa Fila

Regras lógicas: <br>
1. Visita todos os adjacentes <br>
2. Depois os adjacentes dos adjacentes <br>
3. Continua até a fila esvaziar <br>

```text
A
B C D E
F G
H I


````

### 🧠 Comparação DFS × BFS
| Critério | DFS | BFS |
| :--- | :--- | :--- |
| Estrutura auxiliar | Pilha | Fila |
| Exploração | Profunda | Por níveis |
| Caminho mínimo | Não | Sim (não ponderado) |
